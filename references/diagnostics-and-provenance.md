# 版本、来源与待核验项

## 资料边界

Skill 只根据以下本地资料整理：

- `components-docs/入门教程/`：创建组件、创建组件文件、组合与布局、嵌入、全宽、属性、筛选。
- `components-docs/组件使用教程/`：Markdown、卡片、摘录、倒计时、正计时、日期进度、时钟、统计数字、自定义组件、数据视图、图表。
- `components-docs/高阶教程/JsQuery 使用教程/` 与 `组件脚本使用教程/`。
- `components-docs/快速实践/`：数据视图、统计数字、打卡、书库、AI 按钮案例。
- `components-docs/安装激活/`、`插件下载/`、`常见问题/`、`归档/样式美化/`、`更新记录/`。

图片只作为界面证据；不会从图片反推未导出的配置字段。视频没有纳入事实依据。

## 版本线索

- 网格布局在 2.0 引入。
- 列表布局来自 1.0；资料建议用网格替代。
- 2.3.2504024 每夜版开始支持摘录“指定标题下的内容”和“包含指定标签的内容”。
- 3.0 资料描述甘特视图、引用组件、包裹为组合、移动端标签页下拉、一键边框/阴影、组件文件独立图标、数据视图和统计数字增强。
- 组件库索引标记最低版本 `3.0.0`；AI 集成标为 `3.1.0+`。资料未给出完整当前版本/API 兼容矩阵。

## 必须标注的缺口

1. 多个内嵌多维表格只留下 `原文未导出`，包括属性类型、Components 内置属性、视图类型选项、统计方式/统计数据、视图属性映射、任务属性、按钮修改属性、图表数据等。
2. `useDataStorage` 说明称 `getData`/`setData`，示例调用 `getData`/`saveData`；保存函数必须在当前版本核验。
3. 自定义 JSX 示例的标签在导出中确实缺失，不能作为可运行代码模板。
4. 脚本文档的部分组件集成表格未导出，不能声称脚本支持的完整组件清单。
5. Components 原生“设为主页”没有完整操作，索引提到的 XDB 节点未下载。
6. “跨组合移动”没有完整的目标选择、确认和撤销步骤。
7. “引用组件”没有完整字段、嵌套行为和引用更新规则。
8. 网格和移动端的精确尺寸、断点、布局序列化格式没有说明。
9. 归档样式包是第三方旧版参考，需要 Style Settings，不是默认依赖。
10. 倒计时/正计时颜色格式写成 `RGBA、HSLA、HSE`，其中 `HSE` 疑似笔误；以当前控件为准。
11. 倒计时“显示结束时间”的文字与典型未来倒计时场景存在歧义。
12. 下载页附件、历史版本附件、GitHub FAQ 权限范围和安全存储说明不完整。

## 证据规则

- 文档明确的 UI 步骤可以直接写成操作清单，但仍需注意版本前提。
- 逻辑正确但未出现于 Components UI 的 SQL、Dataview、抽象 YAML、React 宿主对象等只能标为 `【示意】`。
- 有截图但无文字说明的按钮、字段和菜单不升级为硬契约。
- “当前版本支持”只在原文明确或多个文档一致时使用；否则写“资料记载/待核验”。
- 完成报告必须区分已运行验证与文档推导。没有打开用户 Obsidian 库时，不要声称组件已创建、渲染或写回成功。
