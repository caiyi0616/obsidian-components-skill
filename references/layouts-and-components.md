# 布局与基础组件

本页整理组件文件、组合布局、嵌入和基础组件的可复现路径。涉及的来源主要是 `入门教程/创建组件.md`、`创建组件文件.md`、`组合与布局.md`、`嵌入组件文件到笔记中.md`、`组件使用教程/Markdown 组件.md`、`卡片组件.md`、`摘录组件.md`、`倒计时组件.md`、`正计时组件.md`、`日期进度组件.md`、`时钟组件.md` 和 `更新记录/3.0 有什么变化？.md`。

## 创建组件文件

`【文档已确认】`

1. 确认 Components 已安装、激活，并确认“通用/基本设置”中的“新建文件默认存放路径”。路径相对于库目录，不能填盘符；文档中出现过 `components` 与 `components/view` 两种默认目录描述，以当前插件设置为准。
2. 在笔记或文件夹上右键选择“创建组件”，或者打开命令面板（Mac `command+p`，Windows `ctrl+p`），搜索 `components` 后执行“创建组件”。在目录上右键可以让文件直接创建到目标目录。
3. 输入组件文件名，点击“创建文件”。文件通常会自动打开。
4. 空组合中点击“+点击此处添加组件”，选择需要的子组件。
5. 先用一个组件确认渲染，再进行布局和数据配置。

组件文件本质上是组合组件/画布，可以嵌套组合。

## 组合和布局

当前组合布局文档列出 5 种：网格、标签页、垂直标签页、分栏、列表。旧文档只列 3 种，属于版本差异；以当前插件 UI 为准。

| 布局 | 适用 | 已确认行为 |
|---|---|---|
| 网格 | 桌面仪表盘、自由排布 | 可拖拽组件位置和宽高；调整完成后可锁定 |
| 标签页 | 分类入口、少量互斥区域 | 点击标签切换；可重命名、复制、删除；支持拖拽排序和嵌套层级 |
| 垂直标签页 | 侧向分类导航 | 标签栏在左侧；可拖拽调整标签栏宽度 |
| 分栏 | 同行并列、嵌套组合 | 子组件水平排列；移动端自动转为从上到下的列表；嵌套场景性能通常优于网格嵌套 |
| 列表 | 简单纵向排列 | 1.0 时代布局，可用网格替代 |

`【文档已确认】`网格不建议再次嵌套网格，可能有性能问题。可以在网格中嵌套标签页、垂直标签页或分栏。网格右键菜单支持创建、编辑、复制、跨组合移动、删除；鼠标必须位于已有子组件上，命中嵌套组合时操作对象是组合本身。3.0 可在组件 `···` 菜单选择“包裹为组合”，省去先创建组合再跨组合移动的步骤。3.0 删除会显示红色遮罩和确认框。

调整网格后，在设置区域点击锁图标锁定；锁定后不能移动或调整尺寸，再次点击解锁。3.0 可一键为子组件添加/移除边框和阴影。移动端标签页列表会自动收缩为下拉列表；网格和垂直标签页的具体断点未记录。

## 嵌入、全宽和主页

### 嵌入

`【文档已确认】`

- 在笔记中创建组件时，插件会自动插入组件文件双链。
- 手动嵌入使用 `![[组件文件名]]`。
- 下拉列表搜不到 `.components` 文件时，在“设置 → 文件与链接”开启“检测所有类型文件”。
- 也可以把组件文件从文件列表拖到笔记区，让 Obsidian 生成双链。
- 3.0 的“引用组件”用于在页面或组合中选择已有组件文件复用；完整字段、嵌套规则和更新规则未给出，标为 `【待核验】`。

### 全宽

`【文档已确认】`单文档方案是在库的 `.obsidian/snippets/` 创建 `editor-full.css`，启用 CSS 片段，再给目标笔记添加 `cssclasses: editor-full`：

```css
.editor-full {
  --file-line-width: 95vw;
  --line-width: 95vw;
  --container-img-width: 100%;
  --table-wrapper-width: 100%;
}
```

关闭“设置 → 编辑器 → 缩减栏宽”是全局方案，不能按单个笔记控制。具体变量受主题和 Obsidian 版本影响，使用前检查现有主题。

### 主页/仪表盘模式

Components 文档没有给出“设为主页”的完整原生操作；索引提到的 XDB 主页节点未导出，因此不要编造菜单路径。可复现的主页组合模式是：

1. 创建外层网格并先调好桌面布局，最后锁定。
2. 顶部放 Markdown 导航、时钟、日期进度；中部放数据视图、任务清单或摘录；底部放统计数字、图表或其他数据组件。
3. 按功能分区时，网格内部使用标签页/垂直标签页/分栏，不再嵌套网格。
4. 导航可用 Markdown 文本内容插入双链，也可用卡片组件作为入口按钮。
5. 把组件文件拖到侧边工作区并设置图标，作为常驻入口；3.0 支持“修改组件文件图标”。

以下是导航内容的 `【示意】`，双链名称必须替换为库中真实文件：

```markdown
> [!INFO]
> - [[领域.components|领域]]
> - [[工作.components|工作]]
> - [[日记.components|日记]]
> - [[知识管理.components|知识管理]]
```

## 基础组件选择

| 组件 | 关键配置（文档已确认） | 适用 |
|---|---|---|
| Markdown | 内容类型为文件路径或文本内容；支持 Markdown、链接、脚注、双链、嵌入和内嵌查询；有边框、阴影、背景/文字色、最大高度 | 导航、说明、嵌入笔记、代码块 |
| 卡片 | 标题、描述、图片；标题图标支持 Lucide；图片可自适应或填充，位置可左侧/上方；动作可执行命令、打开链接、打开文件、调用 Templater | 主页入口和操作按钮 |
| 摘录 | 内容类型：全文、块、指定标题下内容、包含指定标签内容；图片来源：无、网络链接、文档属性、文档首图；需用筛选控制范围 | 日记/读书回顾 |
| 倒计时 | 结束时间；可按天/周/月/年重复；显示单位为年/月/日/时/分/秒任意组合；可显示结束时间和图片/模糊背景 | 截止日期、节日 |
| 正计时 | 开始时间；显示单位任意组合；可显示开始时间；支持图片/模糊背景 | 项目、入职等持续时间 |
| 日期进度 | 开始/结束时间可预设或自定义；可显示日期/进度指示器；进度条或圆环 | 今日、季度、年度进度 |
| 时钟 | 圆形钟或方形钟；可显示当前时间/日期；可配置指针、背景、刻度颜色 | 主页和侧边栏 |

基础组件的具体 UI 标签、颜色格式和部分字段受版本影响。倒计时/正计时资料把颜色格式写成 `RGBA、HSLA、HSE`，最后一项很可能是笔误；以当前控件为准。

## 可复用主页组合

- **导航主页**：Markdown + 卡片 + 标签页；卡片动作打开真实文件或链接。
- **每日仪表盘**：网格外层；时间区用时钟/正计时/倒计时，进度区用日期进度，回顾区用摘录，数据区用数据视图/统计数字，导航区用 Markdown/卡片。
- **随机回顾**：摘录按日记目录筛选，内容类型选择“指定标题下的内容”，例如 `## 每日总结`；图片来源可选“无”。
- **数据主页**：表格先作为维护入口，再复制组件切换画廊、看板、列表或日历；通过引用组件复用稳定的小组件。
