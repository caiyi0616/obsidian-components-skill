# 数据视图与查询

本页是 Components 数据视图的配置参考。来源主要是 `入门教程/认识属性.md`、`数据筛选.md`、`组件使用教程/数据视图/`、`组件使用教程/统计数字.md`、`组件使用教程/图表组件/`、`高阶教程/JsQuery 使用教程/index.md` 和快速实践文档。

## 数据准备

先约定每个记录对应的文件，明确：

- 目标目录和是否递归纳入子目录。
- 只纳入哪些文件类型。表格的属性写回仅适用于 Markdown；非 Markdown 没有自定义属性。
- 属性名、类型、空值、候选值和日期格式。笔记属性和文件属性都能参与筛选；视图属性是数据视图层的扩展。
- 文件名、路径、创建/修改时间等 Components 内置文件属性的具体可选名必须在当前 UI 中核验；完整清单在源文档未导出的表格中。
- 书库、日记、项目等场景不要把模板、附件或隐藏文件意外纳入，除非用户明确需要。

视图中的属性修改会同步到笔记属性，笔记中的修改会刷新视图。按钮属性是例外：它是视图中的行为，不会在笔记属性区创建同名属性。

## 配置顺序

建议按以下顺序，每一步观察结果后再继续：

1. 创建“数据视图”组件。
2. 配置文件目录/范围。
3. 配置筛选。
4. 配置排序。
5. 按需配置分组。
6. 添加、导入、隐藏和排序视图属性。
7. 最后选择表格、画廊、看板、列表、日历或甘特视图。

## 筛选

筛选条件由“属性名、比较符、期望值”组成；多个条件默认是“且”，也可以切换为“或”。属性名包含全库属性和 Components 内置属性。比较符包括：

- 通用：等于、小于、小于等于、大于、大于等于、不等于、包含、不包含、有值、无值、正则匹配。
- 复选框：已勾选、未勾选。
- 日期：晚于、晚于等于、早于、早于等于；期望值可以是具体时间或相对时间。

相对时间适合最近 30 天、本周、本季度等场景。条件组允许组内单独设置连接关系；条件可以拖拽排序，也可以跨组移动。用“有值/无值”时不需要填写期望值。

### 例：日记目录

`【文档已确认】`日记快速入门使用：

```text
文件路径 -> 包含 -> 01_日记
```

再配置：

```text
排序：文件名 -> 降序
新建笔记位置：01_日记
文件名格式：{{date: YYYY-MM-DD}}
```

目录名、日期格式和新建位置应替换为用户实际设置。

## 排序和分组

排序项可以按文件名或其他属性升/降序；具体候选属性以当前 UI 为准。分组配置一个分组属性后，筛选结果按相同属性值分组；空值会进入 `未分类的组`（英文 `No Status Group`）。

分组支持分组名升序、降序、自定义；自定义时在配置页拖动分组名，也可以在视图拖动分组标题调整顺序。可折叠/展开、隐藏/展示分组，并添加没有数据的静态分组。内链型分组名可以点击打开关联文件；按“文件父目录”分组时跨组拖动会移动文件目录。看板天然分组，日历不支持普通分组。

## 五类视图和 Gantt

| 视图 | 用法和写回行为 |
|---|---|
| 表格 | 每行一个文件、每列一个属性；支持单元格编辑和多选批量移动目录、修改属性名、修改属性值、添加/移除列表值 |
| 画廊 | 每个文件为卡片；卡片大小小/中/大只决定最小宽度；封面可为图片、文本、指定标题内容或隐藏；图片可放顶部/左侧并选择填充方式 |
| 看板 | 多列展示，按分组属性形成列；可拖动卡片，Components 自动更新分组属性值 |
| 列表 | 无列头；文件名在左、属性在右；适合简单行展示 |
| 日历 | 依据“日期属性”放置文件卡片；支持日/四日/周/月/列表等类型；配置结束日期属性后支持跨天事件和拖拽调整；当前版本文档对封面在跨天时说明为失效 |
| 甘特 | 横轴时间、纵轴事件；配置日期属性和可选结束日期属性；可按属性动态着色；拖动两端会写回开始/结束日期，未配置结束属性时右端不可拖 |

日历日期属性必须能解析，例如 `2025-01-01`、`2025/01/01`、`2025-01-01T12:00:00`、常见 ISO 8601 或 RFC2822 格式。带星期的 `2025-01-01_星期三`、`2025年1月1日` 等不要直接使用。日历新建数据时会自动添加日期属性；电脑端双击日期区域，手机端单击。

## 视图属性

`【文档已确认】`

- 单个添加：属性配置页点击“添加属性”，输入名称回车。
- 批量添加：点击“添加指定文件”，从文件导入该文件具有的多个属性。
- 如果属性已存在于某篇笔记，Components 会根据笔记属性类型转换为相应视图属性；精确映射表未导出，需核验。
- 删除属性只从视图配置移除，不会从笔记删除。
- 小眼睛可隐藏属性；上下拖拽图标调整显示顺序；表格也可拖拽列头。

## 统计数字

统计数字可以统计笔记数量、任务数量和属性值；支持三种统计方式和三类统计数据，但选择项的完整原文表格未导出，当前 UI 必须核验。可配置筛选范围，再设置计算方式。

已确认的展示设置包括内容前缀/后缀、保留小数位；3.0 还支持千分位，以及把比值显示为进度条。属性值统计可用于文件大小、字词数、出链、入链等。

统计全库 Markdown 的文档技巧是用“任意匹配”：`文件类型等于 md` 或 `文件类型不等于 md`；`.obsidian` 文件夹无法统计。

## 公式属性

公式本质是 JavaScript 行表达式；可使用内置函数和 JavaScript 全局表达式。常用函数：

```javascript
prop("status")
now()
duration(prop("startTime"), prop("endTime"), "day")
ceil(10.1)
floor(10.99)
fixed(10.1234, 2)
parseFloat(fixed(10.1234, 2)) + 1
join([prop("地址"), prop("天气")], "→")
ifElse(prop("睡眠时长") >= 8, "达标", "未达标")
countCompletedTasks()
countUncompletedTasks()
countTotalTasks()
countEmbeds("png$")
countOutgoingLinks("png$")
countBacklinks()
```

`fixed()` 返回文本，参与数学运算前用 `parseFloat()`。日期字符串应使用标准可解析格式；不支持带星期或中文日期的非标准格式。可用 `styles(text, cssStyles)` 和 `html(rawHtmlText)` 做单元格展示，但复杂 HTML 需在当前版本验证。

公式空值、非数字和除零要先处理。不要把通用 SQL、Dataview 查询或抽象 YAML 当成 Components 公式配置。

## JsQuery

JsQuery 是筛选中的条件类型，和可视化筛选可以组合使用：在筛选页面“添加条件”旁的小箭头中选择“添加 JsQuery”。

`$item` 是当前数据项，`$parentFile` 是组件嵌入到 Markdown 笔记时的宿主笔记；组件单独打开时 `$parentFile` 可能不存在。二者都是 `PageData`，含 `frontmatter`、`tasks`、`TextStats` 等属性，但完整字段表未导出，使用前核验。

筛选文件大小大于 1 MB 的 PNG 是文档示例：

```javascript
$item.size > (1024 * 1024) && $item.fileExtension === "png"
```

按宿主复盘笔记的时间范围筛选是可复用模式：

```javascript
$item.frontmatter.createDate >= $parentFile.frontmatter.startDate &&
$item.frontmatter.createDate <= $parentFile.frontmatter.endDate
```

frontmatter 属性名含空格时用中括号；列表属性可用 `includes()`。任务示例：

```javascript
$item.tasks.some(t => t.status === " ")
$item.tasks.some(t => t.status === "!")
$item.tasks.some(t => t.text?.includes("#task"))
```

处理 `$parentFile`、日期属性和缺失 frontmatter 时要加空值保护；未在当前版本测试前，不要承诺所有 PageData 字段都可用。

## 图表

图表数据集由筛选结果决定，每行是文件、每列是属性。柱状图/折线图配置横轴属性、一个或多个纵轴属性，纵轴可选求和等计算方式；配置多个纵轴时不能使用数据分组。按月统计可将创建时间转换成年-月；按类别分组后按月展示趋势。热力图教程存在，但完整配置字段需要按源文档和当前 UI 核验。

## 按钮和任务清单

按钮属性可执行：移动文件到指定目录、删除文件、修改多个属性、应用属性模板、执行脚本。移动目录支持 `archive/{{date:YYYY-MM}}` 这类 Obsidian/Moment 日期变量；删除按钮没有二次确认。属性模板是普通 Markdown 文件，frontmatter 中未指定的属性保持原值。

任务清单属性能展示、编辑、添加和完成笔记任务；默认新任务写在当前文件最后一行，也可在设置中选择保存位置。回车完成编辑，Shift+回车换行；点击复选框改状态；Tasks 风格自动记录可在创建/完成时加入日期。Obsidian 原生不支持任务块属性，这些任务属性并非官方格式。

## 不要直接使用的示例

下面这些是 `【示意】`，不能直接粘贴为 Components 配置：

- `TABLE ... FROM "Books"`、`dataview TASK`、`dv.pages()` 等 Dataview 查询。
- `source: { directory: ... }`、`layout: { desktop: ... }` 这类抽象 YAML。
- 未在当前 UI 确认的字段名、颜色、视图序列化格式和组件注册接口。
